# everything in its right place — the edit (v2)

A 4:11 (250.9s) montage of the latest real tech demo footage, cut to the
structure and pacing of Radiohead's "Everything In Its Right Place" (Kid A).
Ships silent on purpose: the track is copyrighted, so the song is NOT
included. Drop your own MP3 in with add_audio.sh (one command) or send the
MP3 back and it gets muxed for you.

## files
- everything-in-its-right-place.mp4 — full-quality 1080p24 (silent track)
- everything-in-its-right-place_preview_v2.mp4 — small phone preview
- add_audio.sh — one-step mux: ./add_audio.sh your-song.mp3
